#     python -m venv .venv && .venv/bin/pip install -r requirements.txt

#     --quantize additionally needs bitsandbytes built for the Orin's sm_87.

#     "named symbol not found", so take it from the Jetson index instead:
#       pip install --index-url https://pypi.jetson-ai-lab.io/jp6/cu126 bitsandbytes
#
#   macOS / Apple silicon (--backend mlx), the verification path:
#     python -m venv .venv && .venv/bin/pip install -r requirements-mlx.txt
